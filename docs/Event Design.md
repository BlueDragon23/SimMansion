Events are designed to disrupt the normal flow of the game and force the player to make some different choices to what they would normally make. The main ways to do that could be
- Resource requirements. This could even be dynamic. If a player has been neglecting one stat, generate an event that requires more of that resource
- Trait requirements. Requiring a particularly room or category of rooms encourages including different elements. This could also be triggered by player choice, e.g. having children

Events should probably scale based on current stats. That allows for re-use of events throughout a game while still being challenging. It might not make sense for all events though, but we'll see.
